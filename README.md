# One Line, One Laugh

A tiny deterministic program that writes a single funny line to `/output/entry.txt`. It uses only the Node.js standard library, makes no network calls, and produces the exact same bytes on every run — one self-contained joke, no setup, no randomness.

## Run it

```sh
node main.ts
```
